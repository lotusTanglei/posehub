# Fix MySQL Cluster Configuration

I will fix the issues preventing the MySQL Cluster service from starting, specifically the invalid `proxysql` image tag and the missing configuration file.

## 1. Update `docker-compose.yml`
I will edit `posehub/mysql/cluster/docker-compose.yml` to:
-   Change the `proxysql` image tag from `2.5.0` (which does not exist) to `2.5.5` (a stable, existing tag).
-   Remove the obsolete `version: '3.8'` line to suppress the warning.

## 2. Create `proxysql.cnf`
I will create a new configuration file `posehub/mysql/cluster/proxysql.cnf` with a standard configuration that:
-   Defines **Admin Variables** (admin/admin).
-   Defines **MySQL Variables** (interfaces, threads).
-   Configures **Hostgroups**:
    -   **HG 10 (Writer)**: Points to `mysql-master`.
    -   **HG 20 (Reader)**: Points to `mysql-slave1` and `mysql-slave2`.
-   Sets up **Query Rules** for Read/Write splitting.
-   Configures the **Monitor User** (using `root` as defined in the compose file).

## 3. Verify Fix
After applying these changes, I will run the runtime validation script specifically for this service (`./validate_runtime.sh mysql/cluster`) to ensure it starts successfully.
