# Create and Run Docker Compose Validation Script

I will create a shell script to automate the validation of all `docker-compose.yml` files in the repository.

## 1. Create `validate_compose.sh`
I will create a file named `validate_compose.sh` in the root directory with the following logic:
-   **Shebang**: `#!/bin/bash`
-   **Discovery**: Use `find . -name "docker-compose.yml"` to locate all compose files.
-   **Loop**: Iterate through each file found.
-   **Validation**: Run `docker-compose -f "$file" config -q` for each file.
    -   The `-q` flag suppresses output for valid files, keeping the run clean.
    -   Capture the exit code to determine success or failure.
-   **Reporting**:
    -   Print "✅ Valid: [filepath]" for successes.
    -   Print "❌ Invalid: [filepath]" for failures, and display the error output from `docker-compose` to help debug.
    -   Maintain a count of passed and failed files.
-   **Summary**: Print a final summary of Total, Passed, and Failed files.
-   **Exit Code**: Exit with status 1 if any files failed, 0 otherwise (useful for CI).

## 2. Make Executable
I will run `chmod +x validate_compose.sh` to make the script executable.

## 3. Execute and Report
I will run the script immediately after creating it and present the results to you.
